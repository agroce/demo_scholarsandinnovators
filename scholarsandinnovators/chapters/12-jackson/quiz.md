## Part A — Multiple choice

**1.** What was Jackson's first software project?

- (a) A compiler for his father's company
- (b) An operating system at MIT
- (c) A system for managing engineering jobs on the London Underground
- (d) Adobe Lightroom

**2.** How does concept design differ from object-oriented design, according to Jackson?

- (a) Concepts are aggregates of functionality that cut across the individuals in the problem domain, instead of being grouped by them
- (b) Concepts have no state
- (c) Concepts can only be implemented in functional languages
- (d) Concepts replace user interfaces

**3.** Jackson's username example shows that relational thinking prompts you to ask:

- (a) how long a username can be
- (b) whether usernames can contain spaces
- (c) whether usernames should be encrypted
- (d) whether two users can have the same username

**4.** Which of these is *not* one of the three biggest advances Jackson names?

- (a) Better programming languages
- (b) Agile methods
- (c) Interfaces as weak specifications
- (d) Domain modeling

**5.** What made Adobe Lightroom an exemplar for Jackson?

- (a) It was formally verified in Alloy
- (b) It had the most features of any photo editor
- (c) Its team thought its concepts through carefully, replacing layers with a simpler history of actions
- (d) It was built by a very small team in one month

**6.** Why does Jackson expect a reversal of the Agile attitude toward documentation?

- (a) Regulators will require documentation
- (b) Code becomes easy to generate, so the specifications (prompts) become the valuable artifacts
- (c) Agile has been proven not to work
- (d) LLMs cannot read code

**7.** What does Jackson say is the most important thing you can do to make software delightful?

- (a) Eliminate friction
- (b) Add animation
- (c) Add more features
- (d) Make it free
