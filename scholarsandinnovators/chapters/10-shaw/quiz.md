## Part A — Multiple choice

**1.** What example convinced Shaw that abstract data types miss something important about a system's organization?

- (a) A compiler
- (b) A text editor
- (c) An operating system
- (d) A database

**2.** In Shaw's model, how does a professional engineering discipline emerge?

- (a) Science fuses with organized practice that grew out of craft
- (b) Government licensing creates it
- (c) Mathematics is developed first, then applied
- (d) A single influential textbook defines it

**3.** According to Shaw, how can progress in programming languages be measured?

- (a) By execution speed
- (b) By the number of keywords
- (c) By the intuitive size of the abstractions we don't look inside
- (d) By the number of programmers using them

**4.** In Shaw's cruise control example, why did the car speed up while hydroplaning?

- (a) The software had a null pointer error
- (b) The driver set the wrong speed
- (c) The throttle was broken
- (d) The front-wheel speed sensor was a proxy that misread the car's actual motion

**5.** Why did Shaw, Wulf, and London consider it worthwhile to spend as much time debugging the formal specification as the code?

- (a) The spec and code offered different points of view, each revealing flaws in their thinking
- (b) The specification was required by their funding agency
- (c) Code cannot be debugged without a specification
- (d) The specification was longer than the code

**6.** What does Shaw propose to give developers the time to "do the stuff we know we should do"?

- (a) Banning C
- (b) Making software vendors liable, by limiting license agreements that disclaim merchantability and fitness
- (c) Requiring formal verification of all software
- (d) Hiring more testers

**7.** Shaw complains that a speaker at ICSE misunderstood "wicked problems" as:

- (a) problems with security implications
- (b) problems caused by bad management
- (c) problems that can't be solved by computers
- (d) just complicated, hard problems
