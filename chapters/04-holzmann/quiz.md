# Quiz — Chapter 4: Gerard Holzmann

*About 20 minutes. Multiple choice: 2 points each. Short answer: 5 points each. Short essay: 10 points. Total: 34 points.*

---

## Part A — Multiple choice

**1.** What lesson did Holzmann draw from debugging punch-card programs as a student?

- (a) When there's a mistake, it is almost always the programmer's, not the machine's
- (b) ALGOL 68 was too complex to use
- (c) Computers make frequent errors that programmers must work around
- (d) Batch computing should be abolished

**2.** Which subjects does Holzmann say are most important for a working programmer to study?

- (a) Logic, automata theory, and philosophy
- (b) Web frameworks and cloud deployment
- (c) Agile methods and project management
- (d) Machine learning and statistics

**3.** Cobra differs from most static analyzers because it:

- (a) proves full functional correctness
- (b) requires no knowledge of automata theory
- (c) only analyzes Java code
- (d) is interactive, answering queries quickly enough to use during code reviews

**4.** Holzmann's example of theory that had "zero applications" until a later discovery is:

- (a) relational databases, until SQL
- (b) public-key cryptography, until the web
- (c) omega (Büchi) automata, until Pnueli's linear temporal logic
- (d) lambda calculus, until Lisp

**5.** According to Holzmann, why is writing a tool's manual important?

- (a) Manuals are needed for software patents
- (b) Explaining it to a stranger reveals design decisions that don't make sense
- (c) Bell Labs required it in the "I Am Great Report"
- (d) Users rarely read source code

**6.** Holzmann's process-improvement method at JPL centers on:

- (a) daily stand-up meetings
- (b) eliminating the requirements phase
- (c) recording, for every defect, the phase where it was introduced and where it was found, then shortening how far bugs "travel"
- (d) replacing all testing with model checking

**7.** Why does Holzmann rewrite contributed extensions to Spin himself?

- (a) Spin's license forbids outside contributions
- (b) He has to maintain and fix the code, which requires understanding every line
- (c) He doesn't trust other people's algorithms
- (d) Other contributors write in SML/NJ

## Part B — Short answer (3–5 sentences each)

**8.** Holzmann says software engineering at JPL was very different from his attempts to offer bug-finding tools to AT&T business units. Explain the difference and the reason he gives for it.

**9.** Holzmann suggests that the way to tell whether an AI system is "broken" is "to treat it as you would a human being. You ask it questions." What kind of testing is this, and what is its main limitation compared to model checking?
